## 2. Dependências Externas Pendentes de Contratação / Credenciamento (Operando em Homologação com Fluxo Manual Funcional)

- **DataJud CNJ:** configurar `DATAJUD_API_KEY` no servidor (piloto validável para TJSC, TRF4 e TRT12).
- **DJEN / Domicílio Judicial Eletrônico / eproc / PJe / e-SAJ:** homologação institucional/certificados antes de ativar `JUDICIAL_CONNECTORS_ENABLED=true`. Captura automática de ciência permanece bloqueada por padrão.
- **Gotenberg / OCRmyPDF:** containers privados na rede interna (`GOTENBERG_URL`, `OCR_WORKER_URL`).
- **Documenso:** credenciamento e `DOCUMENSO_API_URL`, `DOCUMENSO_API_KEY`, `DOCUMENSO_WEBHOOK_SECRET`.
- **PIX / Boleto e NFS-e Municipal:** seleção do provedor + código municipal (`BILLING_API_KEY`, `NFSE_PROVIDER`, `NFSE_MUNICIPALITY_CODE`).
- **Supabase / Meta WhatsApp:** provisionamento de projeto Supabase com aplicação das migrations `001`–`066` e credenciais WABA no ambiente alvo.
